COLLABORATION WORKFLOW
- Each member clones the repository and creates a task-specific branch.
- Members commit changes with clear, descriptive commit messages.
- Members push their branches to GitHub.
- The group representative reviews and merges completed branches into main.
- Use GitHub Issues to track tasks, questions, and problems.

GIT COMMANDS
1. git clone https://github.com/zecynon7/git-activity-4.git
2. git checkout -b task-your-name
3. git add .
4. git commit -m "Describe your changes"
5. git push origin task-your-name
6. git checkout main
7. git pull origin main
8. git merge task-your-name
9. git push origin main
